# Hi, I'm Sebastian 👋

I work at the intersection of software engineering and machine learning: backend systems, data pipelines and ML models. M.Sc. student in Computer Science (AI Methods) at Warsaw University of Technology.

## Featured

**[Moodle Teaching Bot](https://github.com/EduTechBots/moodle-teaching-bot)**
A Moodle plugin with a RAG-based assistant that generates quizzes and learning materials from course content. Bachelor's thesis project, presented at IJCAI-ECAI 2026 ([paper](https://ijcai.org/proceedings/2026/0984.pdf)).
`FastAPI` `PostgreSQL` `ChromaDB` `MinIO` `Docker`

**[Crypto Options vs Rates](https://github.com/Sebislaw/Crypto-Options-vs-Rates)**
A Lambda-architecture big data system relating Polymarket prediction-market data to Binance crypto rates, with batch and streaming paths merged in a serving layer.
`Kafka` `NiFi` `Spark` `Hive` `HBase`

## More projects

- **[Computational Intelligence](https://github.com/Sebislaw/Metody-Inteligencji-Obliczeniowej)**: from-scratch NumPy implementations of an MLP (backpropagation, Adam, L1/L2, early stopping), Kohonen maps and genetic algorithms (cutting stock, neural network training).
- **[Biometrics](https://github.com/Sebislaw/Biometria)**: three solo projects: an image-processing app built from scratch (filters, thresholding, histogram operations, morphology, convolutions), iris recognition with Daugman's iris code, and fingerprint minutiae detection with K3M thinning.

- **[Astronomical object classification](https://github.com/Sebislaw/Klasyfikacja-obiektow-astronomicznych)**: SDSS17 dataset, with EDA, feature engineering, modelling and a validation report.
- **[Skin disease image clustering](https://github.com/Sebislaw/Klasteryzacja-chorob-dermatologicznych)**: clustering DermNet images using extracted image features.
- **[MyFiles dashboard](https://github.com/Sebislaw/ProjektJA-MyFiles)**: R Shiny dashboard analysing Java, Word and MATLAB files ([demo](https://rowickim.shinyapps.io/MyFiles/)).
- **[Banking Application](https://github.com/Sebislaw/Banking-Application)**: Java desktop app simulating a banking system (group project).
