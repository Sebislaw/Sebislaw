A Moodle plugin with a RAG-based assistant that generates quizzes and learning materials from course content. Bachelor's thesis project, presented at IJCAI-ECAI 2026 ([paper](https://ijcai.org/proceedings/2026/0984.pdf)).

A Lambda-architecture big data system relating Polymarket prediction-market data to Binance crypto rates, with batch and streaming paths merged in a serving layer.
